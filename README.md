# portal-auto-login

打开 Chrome，自动完成陕西师范大学校园网的“移动”登录，省去每次选择运营商、点击登录和确认的操作。

适用于 **Ubuntu + Chrome 120 及以上版本**，当前版本 **0.4.4**。

## 能帮你做什么

- 启动 Chrome 时检测网络，需要认证时自动登录。
- 使用认证页中已填好的学号和密码，自动选择“移动”并完成确认。
- 登录成功后返回新标签页，优先使用已有的空白新标签页，并清理扩展自动打开的认证页。
- 提供独立的“自动登录”开关，随时决定是否启用自动操作。

每次完整启动浏览器只执行一轮。手动断开校园网后，扩展不会再次自动连接。

## 使用前准备

1. 先让电脑连接校园网 Wi-Fi 或校园有线网络。扩展只负责网页认证，不会帮你连接 Wi-Fi。
2. 在 Chrome 中手动登录一次校园网，并保存账号密码，确保再次打开认证页时，学号和密码能自动填入。
3. 确认你使用的是“移动”选项。其他运营商目前不支持。

## 安装

### 使用 ZIP 或项目文件夹

1. 下载并解压 [扩展 ZIP 安装包](dist/portal-auto-login.zip)。如果下载的是整个项目，找到其中的 `extension` 文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`，开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹：安装包解压后的目录，或项目中的 `extension` 目录。
4. 点击工具栏的拼图图标，找到 `portal-auto-login`。可以将它固定到工具栏，方便使用。

安装后请保留该文件夹，不要删除或移动。

### 使用 CRX 安装包

如果你拿到的是 `.crx` 文件，可在 Ubuntu Chrome 中打开 `chrome://extensions`，开启“开发者模式”，将文件拖入页面，按提示添加。若无法安装，可使用上面的 ZIP 方式。

## 开始使用

1. 点击扩展图标，打开“自动登录”开关。首次安装时，开关默认关闭。
2. 确认电脑已连接校园网络。
3. 通过 Chrome 菜单选择“退出”，然后重新打开浏览器，扩展便会开始本轮检测和登录。

检测到网络可用时会静默结束；需要登录时，会显示认证页面并自动操作。点击扩展图标，可以查看底部的状态提示。

关闭“自动登录”后，按原来的方式手动登录即可。重新打开开关，要等下次完整启动 Chrome 才生效；仅新建标签页或窗口不会触发。

## 使用中需要注意

- **在家、使用手机热点或其他非校园网络时，请手动关闭“自动登录”。** 当前版本不会自动区分校园网络和家庭网络。
- **遇到验证码时，请手动完成登录。** 当前版本不支持验证码识别。
- 请等电脑连上校园网络后再打开 Chrome。启动检测失败后，扩展不会一直重试。
- 扩展不会持续监控网络，也不会在手动断开后自动重连。

## 常见问题

**打开浏览器后没有自动登录？**

先检查扩展内部的“自动登录”开关是否打开、电脑是否已连接校园网络，以及认证页是否已填入账号密码。再查看扩展底部的状态提示。若仍未触发，请通过 Chrome 菜单完整退出后重新启动。

**为什么登录成功后还留着认证标签页？**

如果这个标签页原本就是你打开的，扩展会保留它。扩展自己打开的认证页会尝试自动关闭；若关闭失败，会稍后再试。你也可以直接手动关闭，正常情况下不会因此断开网络。

**如何更新？**

使用文件夹安装的用户，用新版文件替换原目录中的内容，再到 `chrome://extensions` 点击该扩展的重新加载按钮。使用 CRX 安装的用户，安装新版 CRX 即可。更新后检查扩展是否已启用，以及内部“自动登录”开关的状态。

## 账号与隐私

扩展使用认证页面已有的账号密码，不额外保存或记录，也不会将它们发送给第三方。启动时会通过公开的联网检测地址检查网络，该请求不携带校园账号密码。标签页访问权限用于识别新标签页和处理认证页面，不上传标签页信息。

这是个人校园网辅助项目，非学校官方扩展。
